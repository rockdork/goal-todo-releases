# 拾光笔记（Goal Todo） · 安装包分发仓

本仓**只放安装包（Releases 附件），不放源码**。源码在私有仓 `rockdork/Goal-Todo`。

## 下载

- **macOS（Apple Silicon）**：`GoalTodo-<版本>-aarch64.dmg`
- **Android**：`GoalTodo-<版本>.apk`

最新版本见 [Releases](https://github.com/rockdork/goal-todo-releases/releases)。

## 说明

- 应用内「检查更新」直连本仓 Releases（Gitee 国内直链更快）。
- 本仓由发布脚本（`scripts/publish-release.mjs`）自动维护，**请勿向本仓提交代码或 Issue**。
- 各产品对应源码仓：rockdork/Goal-Todo（私有）。
